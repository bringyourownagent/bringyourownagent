# Sources

A source is one model at one place: this PC, a home server, or a provider reached with your API key. Local sources do not create a cloud bill. A paid source uses only the key saved in the wallet's protected secret store.

The Sources page shows whether a model is ready, missing, downloading, or disabled. Use Add a model for LM Studio, Ollama, Llama, another OpenAI-compatible server, or OpenRouter. The key field belongs to the wallet window; a key is write-only and is never shown again.
