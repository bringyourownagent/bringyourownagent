# Sources

A source is one model at one place: a program on this PC (the Llama app, LM Studio, Ollama), a home server, or a provider reached with your API key. The wallet holds no model of its own. Local sources do not create a cloud bill. A paid source uses only the key saved in the wallet's protected secret store.

The Sources page shows whether a model is ready, not running, not offered by its program, or disabled. Use Add a model for the Llama app, LM Studio, Ollama, another OpenAI-compatible server, or OpenRouter. One added source serves one skill: text generation or speech to text. The paid speech source, Scribe v2, is always listed; it needs only your OpenRouter key. The key field belongs to the wallet window; a key is write-only and is never shown again.
