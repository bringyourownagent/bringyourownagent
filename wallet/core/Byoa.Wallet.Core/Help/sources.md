# Sources

A source is one model at one place: a program on this PC (the Llama app, LM Studio, Ollama), a home server, or a provider reached with your API key. The wallet holds no model of its own. Local sources do not create a cloud bill. A paid source uses only the key saved in the wallet's protected secret store.

The Sources page shows whether a model is ready, not running, not offered by its program, or disabled. Use Add a model for the Llama app, LM Studio, Ollama, another OpenAI-compatible server, or a provider with your own key: OpenRouter (hundreds of models behind one key), OpenAI, Anthropic, Google, MiniMax, DeepSeek, xAI, Z.ai, Mistral or another OpenAI-style service. A model that is in your default set (the Sources page says so) is the first the wallet offers a site that asks for several models. One added source serves one skill: text generation or speech to text. The paid speech source, Scribe v2, is always listed; it needs only your OpenRouter key. The key field belongs to the wallet window; a key is write-only and is never shown again.

When a site connects, the wallet makes each model the site will use do its simplest job once: speech to text transcribes 3 seconds of audio, text generation writes one short answer (an image model would draw the smallest image it can). The connection waits for that, so the site's first real request does not meet a model that is still starting; a link waits up to about 100 seconds, anything else up to three minutes, and the "Preparing your model" notice shows meanwhile. The switch "Check the models when a site connects" at the top of the Sources page is on by default. Turn it off to skip this; the first request may then be slow.

A model on this PC (or on a server of yours) that thinks before it answers, such as Qwen3.5 or DeepSeek-R1, can spend minutes on its hidden reasoning, and on a slow machine that may be longer than a site waits. Each such model has the switch “Let the model think before it answers” on its card; it is on by default. Untick it for quick answers. A site may also ask for an answer without thinking, and your switch wins over a site that wants thinking. A model that does not think is not changed. Under the switch, a model of the Llama app (or another llama.cpp server) has “Thinking limit, tokens”: the most it may spend on thinking before it must answer, 2000 at first, 0 for no limit. The answer keeps the room the site asked for on top of the limit, and a small model can no longer think in circles for minutes. GLM at Z.ai has the switch too: GLM-5.3 always reasons a little, so unticked the wallet asks it for the lowest level of reasoning. Other models behind an API key are not changed.

If you want to start your models yourself, tick “Never start a model for me” at the top of the Sources page. The wallet then makes no model do a warm-up job, and it sends nothing to a model that is not in memory, so no program starts a model because of a site: the question goes to the next model that is running, or the site hears that AI is unavailable. The Sources page says “loaded” or “not loaded” beside a model when its program tells. This works with the programs that say what is in memory: the Llama app, LM Studio and Ollama. For another server the wallet cannot tell, and it does not hold the model back. It is off by default: then the program starts the model a site's request needs.
