# Privacy

Audio and prompts are sent only to the source selected by the wallet. Local sources keep data on this PC. A provider source receives data through its own endpoint, using your key; the key is never logged or returned by the wallet. {{key-protection}}

Activity stores times, sites, skills, source labels, outcomes, fallback notes, and cost. It does not store audio, transcripts, prompts, or API keys. Through the wallet, a connected AI agent sees only what its tools return, within its access. A program that runs as you can read the wallet's files directly, so connect only agents you trust.
