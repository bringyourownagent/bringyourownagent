# Get started

The Get started card sits at the top of My models, and at the top of Sites for as long as the wallet has no text model at all. It offers three ways to a first answer, and all three are free. Anything added from the card behaves exactly like a model added with Add a model: it lands on My models, joins your route, and you can edit, disable, reorder, or remove it there.

## A model on this computer

The card looks for model programs on this computer (the Llama app, LM Studio, Ollama) and lists the models they serve, the ones already in memory first. Press Add next to a model and it is added the same way as in the Add a model window; a model you already added is not offered again. A program that does not answer right now is not offered, and nothing here starts a program for you. When nothing answers, the card shows a Get Llama link — it only opens llama.app in your browser; you install Llama yourself.

## Sign in with OpenRouter (a free account)

OpenRouter is one key for hundreds of models, and some of them are free. The sign-in happens in your browser: the wallet opens the OpenRouter page, you make or use a free account there, and OpenRouter sends the wallet your own API key. The wallet listens for this answer on your computer only, checks that the answer belongs to the sign-in it started, and keeps the key the same way the Add API key window does — it is never shown or logged again. Afterwards the card suggests a few free models (the biggest context first); untick what you do not want and press Add the ticked models. You can add more models, free or paid, any time with Add a model.

## Free demo models, no sign-up

Two public services answer with no key and no account at all: LLM7.io and OVHcloud AI Endpoints. The card labels them demo and asks one plain confirmation first, because a public service has real limits: it may keep what you send, it is slow and rate-limited (OVHcloud's anonymous tier is about two requests a minute), and it is not for private text. A demo model costs nothing and counts no money, but it still counts as cloud: a site that may only use models on this computer never receives it. It also stays out of the sites' default set — a site uses it only after you tick it in that site's window. For a serious start, replace the demo later with a local model or your own OpenRouter key.

## Show all settings

The settings window starts with a short tab list: Sites, My models, and Activity. The "Show all settings" switch at the bottom of the tab list shows the rest (My agents, Agent guard, Skills & fallbacks, Limits, My MCP, Help). Any notice or button that opens a detailed page switches it on by itself, and it stays on.
