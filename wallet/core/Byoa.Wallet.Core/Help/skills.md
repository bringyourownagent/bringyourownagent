# Skills

A skill is a capability, not a vendor or a model name. Speech to text (`audio.transcribe`) turns a short recording into words, with a speech model that runs in a program on your computer (or a home server), or with the paid Scribe v2 behind your own OpenRouter key. Text generation (`text.generate`) writes an answer from a prompt when a compatible text model is available. More skills, including pictures and video, may arrive later.

The wallet checks the skill, language, input size, and the site's grant before a model runs. A source may know one language or many. The website does not choose a provider behind your wallet. A site that works with several different models (a judge that wants the opinions of different AIs) may ask for them and say why; you tick which of your models it gets, it sees only those, and their real names only if it asked for them and you allow it.
