# Add a model

The wallet holds no model. A model runs in a program on your computer, and the wallet only passes requests to it. Choose On this PC to scan the Llama app, LM Studio, Ollama, and other compatible servers, and pick the model the program offers. A program that is not running is shown as “not running”; start it before testing. If no program answers, the window points to Llama (free and open source, from the llama.cpp team and Hugging Face); Get Llama only opens llama.app in your browser, and you install it yourself. Choose Behind my API key for a provider. The wallet keeps the key and shows only “key saved ✓”.

Choose the skill. Text generation needs a text model. Speech to text needs a model that hears audio: for example Qwen3-ASR in Llama (the models that sound like speech models are listed first). One added source serves one skill; add the same model twice to use it for both. Leave Languages empty to take any language. Press Test and read the plain result before pressing Add: the test sends a short sound or a short question, and a model that cannot do it fails with the program's own reason. You can later edit, disable, reorder, or remove an added source.
