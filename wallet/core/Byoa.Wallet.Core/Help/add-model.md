# Add a model

Choose On this PC to scan LM Studio, Ollama, Llama, and other compatible servers. A runtime that is not running is shown as “not running”; start it before testing. If no local model app answers, the window points to Llama (free and open source, from the llama.cpp team and Hugging Face); Get Llama only opens llama.app in your browser, and you install it yourself. Choose Behind my API key for a provider. The wallet keeps the key and shows only “key saved ✓”.

Choose the skill and languages, press Test, and read the plain result before pressing Add. You can later edit, disable, reorder, or remove an added source. The first suggestion is normally local and free; a Russian model may be suggested because it is good for Russian.
