# Connecting your AI agent

The wallet includes `byoa-mcp.exe`, a small MCP bridge over a per-user named pipe. Add it to Claude Code, Codex, or OpenCode using the command shown on Connect your AI agent. The wallet must be running first; the bridge does not start it.

The first connection shows the visitor the agent name and executable path. Allow gives source and model management. Full access is a separate checkbox for site access, limits, paid approvals, and approving other agents. You can switch Full access off or Revoke the agent in Settings → Agents. Every agent change is recorded in Activity.
