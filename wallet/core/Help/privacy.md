# Privacy

Audio and prompts are sent only to the source selected by the wallet. Local sources keep data on this PC. A provider source receives data through its own endpoint, using your key; the key is stored with Windows DPAPI and is never logged or returned by the wallet.

Activity stores times, sites, skills, source labels, outcomes, fallback notes, and cost. It does not store audio, transcripts, prompts, or API keys. A connected AI agent sees only the tools and data its access allows.
